# Code of Conduct

This project follows the [Contributor Covenant v2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful and constructive. Harassment, insults, discrimination and personal attacks are not tolerated — in issues, pull requests, discussions or any other project space.

Report unacceptable behavior to **viepubliquesenegal@gmail.com**. Reports are handled confidentially.
