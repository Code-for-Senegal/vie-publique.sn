## langue

avoir des URL en français pourrait même être bénéfique pour votre référencement, surtout si votre public cible est francophone.

## nom des fichiers pdf

optimiser le référencement. Voici quelques points à considérer :

Utilisation de mots-clés : Le nom "OFNAC\*2022" contient probablement un acronyme (OFNAC) et une année. C'est bien, mais vous pourriez ajouter plus de mots-clés descriptifs.

Utilisation de tirets : Google préfère les tirets (-) aux underscores (\*) pour séparer les mots dans les URL.

Minuscules : Il est généralement recommandé d'utiliser des lettres minuscules dans les URL.

Descriptif : Plus le nom de fichier est descriptif, mieux c'est pour le SEO.

## longuer

Longueur : Des URL plus longues sont généralement moins favorables pour le SEO, bien que ce ne soit pas un facteur majeur.
