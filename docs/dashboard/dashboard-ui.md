Objectif :
design institutionnel clair, sobre et lisible, proche de la maquette fournie.

========================
RÈGLES DESIGN STRICTES (OBLIGATOIRES)
========================

1. INTERDICTIONS (très important)

- PAS de gradients
- PAS de dégradés
- PAS d’effets flashy
- PAS de couleurs saturées type dashboard SaaS
- PAS de bordures colorées épaisses
- PAS de styles “IA” modernes type startup

========================
2. STYLE GLOBAL
========================

Le design doit être compatible avec le mode clair et le mode sombre.

- Utiliser les couleurs de fond issues du thème (light/dark), ne pas hardcoder #FFFFFF
- Cartes : fond légèrement contrasté par rapport au fond principal (clair en light, plus sombre en dark)
- Bordures : fines, discrètes, adaptées au thème
- Design : sobre, institutionnel (type Banque mondiale / rapports publics)

========================
GESTION LIGHT / DARK MODE
========================

Le site supporte un mode clair et un mode sombre.

Contraintes :

- Le design doit fonctionner dans les deux modes
- Utiliser les variables de thème existantes (ne pas hardcoder les couleurs)
- Le dark mode est une adaptation du light mode (pas un design différent)

LIGHT MODE :
- fond blanc
- cartes claires
- style institutionnel

DARK MODE :
- fond sombre uniforme
- cartes légèrement contrastées
- mêmes couleurs adaptées (moins saturées)

INTERDIT en dark mode :
- gradients
- effets glow
- couleurs néon
- style “dashboard startup”

Objectif :
un rendu sobre, lisible, cohérent dans les deux modes

========================
3. KPI (EN HAUT)
========================

Problème actuel :
→ traits colorés sur les côtés (style IA)

À corriger :

- supprimer les bordures colorées latérales
- utiliser des cartes blanches simples
- ajouter une petite pastille ou badge pour variation (vert / rouge)

Structure :

[ VALEUR (très gros) ]
Label (petit)
Variation (petit badge)

Exemple visuel attendu :
- carte simple
- chiffre dominant
- aucun effet inutile

========================
4. BLOCS SECTEURS (TRÈS IMPORTANT)
========================

Objectif :
Ressembler à la maquette (lisible en 2 secondes)

À faire :

- fond légèrement coloré (très léger, pastel)
- PAS de fond saturé
- PAS de dégradé

Couleurs :

- Agriculture → jaune très clair
- Industrie → vert très clair
- Services → bleu très clair
- Social → rouge très clair

IMPORTANT :
La couleur est un fond léger, pas un bloc agressif

========================
5. TYPOGRAPHIE
========================

- chiffres : très gros (focus principal)
- labels : petits
- espacement généreux

Hiérarchie :

Valeur >> Titre >> Texte

========================
6. ESPACEMENT
========================

- augmenter les paddings
- ajouter de l’air entre sections
- éviter effet “compact dashboard”

========================
7. OBJECTIF VISUEL
========================

Quand on regarde la page :

- on voit d’abord les chiffres
- ensuite les blocs secteurs
- ensuite les détails

Pas l’inverse

========================
8. RÉFÉRENCE MAQUETTE
========================

Tu dois reproduire :

- la simplicité
- la lisibilité
- la hiérarchie visuelle

Tu ne dois PAS reproduire :
- les couleurs fortes
- les données
- les effets graphiques

========================
IMPORTANT
========================

Le rendu final doit ressembler à :

- un rapport public officiel
- une publication institutionnelle
- pas un outil SaaS
