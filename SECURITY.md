# Security Policy

## Reporting a Vulnerability

Please do **not** open a public issue for security vulnerabilities.

Report privately via:

- Email: **viepubliquesenegal@gmail.com**
- GitHub: _Security_ tab → _Report a vulnerability_

Include a description, steps to reproduce and potential impact. We aim to acknowledge reports within 72 hours.

## Scope

- The website [www.vie-publique.sn](https://www.vie-publique.sn) and its API routes
- The mobile application (Android / iOS)
- This repository
